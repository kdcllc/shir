Key decisions:
- docs/DESKTOP.md was hardened and now specifies new strings: `separator`, `transposeDownGlyph`, `transposeUpGlyph`.
- shir://ui-ready uses a module-level once-guard in uiReady.ts, set before `await emit`, so StrictMode's concurrent double effect emits once. Tests cover both sequential and concurrent calls (`Promise.all`).
- The song header's `dir` is `firstStrongDirection(title)`. Its lines shrink to content at the start edge (`align-items: flex-start`), and the key/capo line is `dir="ltr"`.
- Colour rule: a CSS2 system-colour fallback declaration comes first. The `color-mix()`/`Mark` value is re-declared in `@supports (color: …)` immediately after its base rule, which keeps the existing cascade order. The goal-local checker `check-colors.mjs` enforces this.
