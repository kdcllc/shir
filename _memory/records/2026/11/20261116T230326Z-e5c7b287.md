Goal g6-editor-import (G6, branch feat/g6-editor-import) — shipped. Adds a ChordPro editor to the desktop app (plain textarea dir="auto", debounced live SongView preview, New/Edit, Save via existing save_song, in-app ConfirmDiscard for unsaved changes), Paste/Convert/Flip import, and Open files (tauri-plugin-dialog 2.8.4 picker + new Rust command read_text_file: UTF-8, one BOM stripped, 1 MB cap, typed FileError TooLarge/NotUtf8/Io; registered before log_webview_error because g5b-contract depends on it staying last).

chord-core gained importText(text, {rtlColumns}) → {chordpro, format, hasRtlChords, warnings}: per-line detection (directives, comments, inline-chord lines and whole literal sections tab/grid/abc/ly/textblock/svg pass through), chord-line heuristic, chord-over-lyric merge by grapheme index, forward snap off whitespace. Import fixtures live in packages/test-fixtures/import/ (separate IMPORT_FIXTURE_NAMES, not ALL_FIXTURE_NAMES) with mirror and logical goldens.

Routing (user decisions): .cho/.chopro/.chordpro files are strict passthrough and auto-saved; .txt files are converted; a converted file with RTL chords-over-lyrics (hasRtlChords) is queued into the editor for preview + Flip before save, keeping a {title: <basename>} fallback via withTitleFallback.
