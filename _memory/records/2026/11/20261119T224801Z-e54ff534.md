Pitfall (g8-library-ui-i18n): test data written by an agent can contain copyrighted lyrics, and task-level evaluation may not catch it.

What went wrong: the E2E implementer used "[C]Hello [G]darkness my old friend" (the opening line of a copyrighted song) as the probe song text in three WebdriverIO specs. The task evaluator ran every spec and mutation and passed the task; only the Phase 5 final audit flagged it, as an auto-fail trigger.

How it was detected: the final auditor read the e2e specs against the hebrew-rtl-chords rule "never use copyrighted lyrics" and confirmed with `git grep -i darkness <base>` that it was new in the goal.

How to avoid: in every implementer package that writes fixtures, specs or sample songs, state "original text only — no lines from real songs", and add a review item to task evaluations of test/E2E tasks (not only fixture tasks) to scan new song text. Neutral placeholder lines ("Morning light on an open road") are enough for direction/badge tests.
