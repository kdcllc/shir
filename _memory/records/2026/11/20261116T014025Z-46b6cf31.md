Goal g4-storage (Shir MVP G4 — Storage). Outcome: shipped on branch feat/g4-storage (10 task commits e33095c…c94c907; Phase 5 audit APPROVED, full Quality Checks green); PR pending, with the windows-latest CI leg as the final gate for the Windows smoke repair.

Built: a SQLite song library behind typed Tauri IPC. apps/desktop/src-tauri/src/db/ (rusqlite 0.41.1 bundled + rusqlite_migration 2.7.0): STRICT `songs` table + FTS5 `songs_fts` (title_norm/artist_norm/lyrics_norm, unicode61 remove_diacritics 0) keyed by songs.rowid and written by Rust in the same transaction; normalize_he (maqaf→space, NFD, strip U+0591–U+05C7, NFC, fold finals, lowercase) for stored text and queries; extract() mirrors chord-core's ChordPro line rules (verified by a 20k-input differential and a chord-core-derived golden). Repo: save/get/list/delete with UUIDv7 ids, fixed-width ms timestamps, 1 MiB byte limit, verbatim text. Search: punctuation → token separators, quoted prefix terms (implicit AND), bm25 then recency, cap 100. commands/: five async tauri-specta commands over Mutex<Result<Connection, DbError>>; an unopenable DB logs one line and every command returns Unavailable. bindings.ts generated in ErrorHandlingMode::Result with a drift test; apps/desktop/src/storage.ts maps failures to typed StorageError (Ipc for non-DbError). Also fixed the windows-latest smoke flake (cmd per-line echo stub → single `type`; ps1 reads logs with FileShare.ReadWrite).

Key decisions: rusqlite pinned to 0.41.1 because no migration crate supports 0.42; named pre-release allowlist (specta, tauri-specta) in the stack guard; git-ignore Tauri's generated permissions/autogenerated like gen/schemas; per-task local commits.
