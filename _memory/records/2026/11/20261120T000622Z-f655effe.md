Delivered: `.github/workflows/release.yml` publishes a GitHub Release (marked Latest, tag vX.Y.Z) after the CI workflow succeeds for a push to main (workflow_run). It releases when the first-parent history since the latest v* tag contains at least one merged feat/* or fix/* PR; the bump is the highest release:major/minor/patch label among those PRs (patch by default; first release uses tauri.conf.json's 0.1.0). Four native builds: NSIS setup.exe on windows-latest and windows-11-arm, AppImage on ubuntu-22.04 and ubuntu-22.04-arm, each asserting `rustc -vV` host triple; version injected with `pnpm tauri build --bundles <b> --config <file>` (no commit back). Assets are renamed `Shir_<v>_<os>_<arch>…`, with SHA256SUMS.txt attached and also embedded in the notes alongside an install section.
